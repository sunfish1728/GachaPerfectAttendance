# 二遊全勤君 — 設計方案 v0.1

## 目標
集合並排程執行各類二游自動化腳本：
- OK 系列（ok-ww 鳴潮、ok 異環 等）
- 一條龍系列（絕區零一條龍、崩鐵一條龍；可兼容三月七助手）
- MAA 系列（MAA、M9A、MaaEnd 等 MaaFramework 系），需「自動跟上腳本變動」
- 通用 exe/bat/ps1

功能核心：定時啟動、任務鏈、啟動前靜音／結束後還原，以及更多人性化功能。

參考（已停更）：https://github.com/learningAHAIC/SGA-Sucrose_Game_Assistant

## SGA 分析結論
- 可沿用：MAA 透過改寫 `config/gui.json` 注入臨時配置（`SGA-cache`），設 `Start.EndsWithScript` 指向 bat 寫完成標記檔，`Start.RunDirectly=True`、`MainFunction.ActionAfterCompleted`；輪詢標記檔判斷完成；pycaw 靜音、psutil 程序管理。
- 要避開：UI 座標寫死、定時條目硬編碼 10 組、GBK 編碼、接法寫死在主程式、等待迴圈無超時。
- 原則：每個腳本接法 = 獨立「適配器」，可熱更新，不需主程式發版。

## 架構
```
GUI (PySide6 + QFluentWidgets)
排程器 ── 任務佇列 ── 執行引擎 ── 全域鉤子(前置/後置)
適配器層（宣告式 YAML + 少量 Python）：OK / 一條龍 / MAA / 通用
```
適配器介面：啟動（參數）、完成判斷（程序結束/日誌關鍵字/標記檔/退出碼）、成敗判斷、清理。

## 各系列接法
| 系列 | 接法 |
|---|---|
| OK | 官方命令列 `ok-xx.exe -t <任務序號> -e`（跑完自動退出）；監控程序結束 + 解析日誌 |
| 一條龍 | 命令列參數啟動一條龍並完成後關閉（**參數待以最新版實測確認**）；程序監控 + 日誌 |
| MAA | 延續 gui.json 臨時配置注入 + 超時 + 結束後還原原配置；新版優先用 MaaFramework CLI/Agent |
| 通用 | 自訂命令、工作目錄、完成條件 |

MAA「自動跟上變動」：適配器標註支援版本範圍與關鍵配置結構 → 啟動前校驗，不符則暫停並通知；適配器定義放 GitHub 倉庫熱更新；監控各工具 Release 提示/自動更新。

## 核心功能
- 排程：多時段、每日/每週、遊戲刷新時間（如 04:00）、開機延遲；可寫入 Windows 工作排程器以從睡眠喚醒
- 任務鏈：拖曳排序，每步失敗策略（重試/跳過/中止）
- 前置鉤子：靜音（記錄各應用原音量）、關指定程式、切解析度/縮放、電源計畫、勿擾
- 後置鉤子：還原音量/解析度、關遊戲與模擬器、關機/睡眠/無

## 人性化功能
1. 使用者在場偵測（鍵鼠活動、全螢幕）→ 延後 + 60 秒可取消倒數
2. 全域緊急停止熱鍵（如 Ctrl+Shift+F12），終止並還原系統狀態
3. 超時與卡死保護（畫面長時間不變 → 截圖、殺程序、重試）
4. 通知推播：Windows、Server醬、Telegram、Discord、Bark、郵件
5. 每日完成看板（解析日誌）
6. 多帳號/多配置
7. 前台互斥排隊；遊戲已手動開啟時先詢問
8. 首次使用嚮導：自動掃描已安裝腳本與遊戲
9. 斷電續跑
10. 歷史紀錄與日誌中心（SQLite）
11. 托盤常駐、開機自啟、UAC 提權
12. 配置匯入匯出/雲端備份
13. 繁中/簡中/英文，全 UTF-8
14. 維護日／版本更新日偵測：遊戲客戶端需更新或伺服器維護時自動跳過並通知，不讓腳本卡在更新畫面
15. 環境預檢：網路連通、磁碟空間、筆電未插電/低電量時延後或跳過
16. 遠端控制：Telegram/Discord Bot 指令（立即執行、暫停今日、查看狀態、緊急停止）
17. 「今日暫停」一鍵開關與假期模式（指定日期區間不跑）
18. 失敗現場保存：失敗時自動截圖 + 打包相關日誌，便於回報
19. 執行耗時統計與預估完成時間（顯示於托盤提示）
20. 模擬器管理：MAA 前自動啟動指定模擬器實例、等待 ADB 就緒（有超時）、結束後關閉

## 技術選型
Python 3.12、PySide6、QFluentWidgets、APScheduler（+ Windows 工作排程器）、psutil、pycaw、pywin32、watchdog、SQLite；Nuitka/PyInstaller 打包，GitHub Release 自動更新。
